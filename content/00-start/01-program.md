## Программа — это список инструкций

Компьютер сам ничего не «понимает». Он умеет только очень быстро и точно выполнять **инструкции** — одну за другой, сверху вниз. **Программа** — это список таких инструкций, записанный текстом.

Представьте рецепт: «возьми два яйца», «разбей в миску», «перемешай». Повар выполняет шаги по порядку. Компьютер — такой же исполнитель, только абсолютно буквальный: он сделает ровно то, что написано, даже если написана ерунда.

Текст программы называют **кодом**, а язык, на котором он написан, — **языком программирования**. В этом курсе язык — **Go**.

## От текста к работающей программе

Процессор не читает Go напрямую. Специальная программа — **компилятор** — сначала проверяет ваш код и переводит его в команды процессора. Отсюда два важных следствия:

1. Если в коде опечатка, компилятор откажется его переводить и покажет **ошибку компиляции** — с номером строки, на которой он запнулся.
2. Ошибки — нормальная часть работы. Их получают все программисты, каждый день. Спокойно прочитать сообщение и найти нужную строку — главный навык, которому вы научитесь в этом модуле.

На этом сайте ничего устанавливать не нужно: код компилируется и запускается, когда вы нажимаете кнопку.

## Первая программа

```go
package main

import "fmt"

func main() {
	fmt.Println("Привет!")
}
```

Эта программа печатает на экран слово `Привет!`. Разберём её по частям:

- `package main` и `import "fmt"` — «шапка». Первая строка говорит, что перед нами запускаемая программа, вторая подключает набор готовых команд `fmt` для печати на экран. Пока просто оставляйте эти строки как есть — подробно они разобраны в следующем модуле.
- `func main() {` … `}` — **главная функция**. Всё, что стоит между фигурными скобками `{` и `}`, компьютер выполнит при запуске — сверху вниз.
- `fmt.Println("Привет!")` — сама инструкция: «напечатай текст и перейди на новую строку».

> **Важно:** пока вы пишете код только **внутри** фигурных скобок `main`. Шапку и строку `func main() {` не трогайте.

## Печать на экран

`fmt.Println(...)` печатает то, что стоит в круглых скобках:

```go
fmt.Println("Меня зовут Go")  // текст — обязательно в двойных кавычках
fmt.Println(42)               // число — без кавычек
fmt.Println(2 + 3)            // посчитает и напечатает 5
fmt.Println("2 + 3")          // это текст: напечатает 2 + 3
fmt.Println("Мне", 30, "лет") // несколько значений через запятую: Мне 30 лет
```

Текст в кавычках называется **строкой**. Компьютер не вникает в её смысл — печатает как есть. Поэтому `2 + 3` без кавычек — вычисление, а `"2 + 3"` в кавычках — просто пять символов.

Если значений несколько, `Println` сам ставит между ними пробелы.

## Порядок имеет значение

Инструкции выполняются строго по очереди:

```go
fmt.Println("Сначала это")
fmt.Println("Потом это")
```

Поменяете строки местами — поменяется и порядок на экране.

## Комментарии

Всё, что написано после `//` до конца строки, компьютер пропускает. Это **комментарий** — заметка для человека:

```go
// Эта строка ничего не делает
fmt.Println("А эта печатает") // пояснение можно дописать и справа
```

## Как читать ошибки

Допустим, вы забыли закрыть кавычку:

```go
fmt.Println("Привет!)
```

Компилятор ответит примерно так:

```text
./main.go:6:14: string literal not terminated
```

Читается это так: файл `main.go`, **строка 6**, позиция 14 — «строка в кавычках не закрыта». Сообщения написаны по-английски, но самое полезное в них — номер строки. На этом сайте строка с ошибкой отмечается красным, а над сообщением появляется пояснение по-русски.

Частые ошибки в самом начале:

| Что написано | Что не так |
|---|---|
| `fmt.Println("Привет)` | не закрыта кавычка |
| `fmt.Println("Привет"` | не закрыта круглая скобка |
| `fmt.println("Привет")` | маленькая буква: команда называется `Println` — регистр важен |
| `fmt.Printn("Привет")` | опечатка в названии команды |

> **Совет:** исправляйте ошибки по одной, начиная с первой, и каждый раз запускайте программу снова. Одна опечатка часто порождает сразу несколько сообщений.

## Как устроены задачи

На вкладке «Практика» есть редактор с заготовкой кода и две главные кнопки:

- **«Запустить»** — выполняет программу и показывает, что она напечатала. Нажимайте сколько угодно: так вы экспериментируете.
- **«Проверить»** — сравнивает то, что напечатала ваша программа, с правильным ответом. Задача засчитывается, когда проверка пройдена.

Вывод должен совпадать с образцом **точно**: те же буквы, тот же регистр, те же знаки препинания.

Застряли — откройте подсказку. А если несколько проверок подряд не прошли, можно посмотреть готовое решение. Но сначала обязательно попробуйте сами: навык появляется, только когда пишешь руками.

@@ quiz
@@ q
Что напечатает программа?
```go
fmt.Println("Чай")
fmt.Println("Кофе")
```
- [ ] Сначала `Кофе`, затем `Чай`
- [x] Сначала `Чай`, затем `Кофе` — каждое слово на своей строке
- [ ] `Чай Кофе` в одну строку
- [ ] Ничего: нужна ещё какая-то команда запуска
@@ explain
Инструкции выполняются сверху вниз, по одной. `Println` после печати переходит на новую строку, поэтому слова окажутся на разных строках.

@@ q
Что напечатает `fmt.Println("10 + 5")`?
- [ ] `15`
- [x] `10 + 5`
- [ ] `"10 + 5"` вместе с кавычками
- [ ] Будет ошибка
@@ explain
Всё, что стоит в кавычках, — это текст (строка). Компьютер его не вычисляет, а печатает как есть, без кавычек. Чтобы получить `15`, нужно написать `fmt.Println(10 + 5)`.

@@ q
Компилятор написал: `./main.go:7:2: undefined: fmt.Printn`. Где искать ошибку?
- [ ] Во 2-й строке, 7-й символ
- [x] В 7-й строке: там опечатка в названии команды
- [ ] В файле `fmt`
- [ ] Ошибка не в коде, нужно просто запустить ещё раз
@@ explain
Формат сообщения такой: `файл:строка:позиция: что не так`. Здесь это строка 7, а `undefined` значит «такого имени не существует» — команда называется `Println`, а не `Printn`.

@@ test
package main

import (
	"io"
	"os"
	"strings"
	"testing"
)

func runMain(t *testing.T) string {
	t.Helper()
	old := os.Stdout
	r, w, err := os.Pipe()
	if err != nil {
		t.Fatal(err)
	}
	os.Stdout = w
	func() {
		defer func() { os.Stdout = old; w.Close() }()
		main()
	}()
	b, _ := io.ReadAll(r)
	lines := strings.Split(strings.ReplaceAll(string(b), "\r\n", "\n"), "\n")
	for i := range lines {
		lines[i] = strings.TrimRight(lines[i], " \t")
	}
	return strings.TrimRight(strings.Join(lines, "\n"), "\n")
}

func TestFirst(t *testing.T) {
	want := "Я учу Go"
	got := runMain(t)
	if got == "" {
		t.Fatalf("программа ничего не напечатала, а нужно:\n%s", want)
	}
	if got != want {
		t.Errorf("программа напечатала:\n%s\n\nа нужно:\n%s", got, want)
	}
}
