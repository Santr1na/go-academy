## Что такое функция

`fmt.Println` — готовая команда: вы пишете её имя, передаёте данные в скобках, и она делает свою работу. **Функция** — это способ создавать **собственные** команды: дать имя куску кода и вызывать его, когда понадобится.

```go
func Double(x int) int {
	return x * 2
}
```

Это функция `Double`: она получает целое число и возвращает его, умноженное на два. Вызывают её так же, как готовые команды:

```go
fmt.Println(Double(21)) // 42
y := Double(5)          // в y окажется 10
```

## Разбор по частям

```go
func Double(x int) int {
//   ───┬── ──┬──  ─┬─
//      │     │     └─ тип результата: функция вернёт целое число
//      │     └─ параметр: имя x и его тип int
//      └─ имя функции
	return x * 2 // return — «верни это значение туда, откуда меня вызвали»
}
```

- **Параметр** — переменная, в которую попадает переданное значение. При вызове `Double(21)` в `x` окажется 21.
- **Тип** пишется после имени: `x int` — «x, целое число». У функции типы нужно указывать всегда — и для параметров, и для результата.
- **`return`** возвращает результат и сразу **завершает** функцию: строки после него не выполняются.

Выражение `Double(21)` в месте вызова как бы заменяется результатом — числом 42. Поэтому его можно печатать, класть в переменную или использовать в вычислениях: `Double(3) + 1`.

## Несколько параметров

```go
func Add(a int, b int) int {
	return a + b
}

func Greet(name string) string {
	return "Привет, " + name + "!"
}

func IsAdult(age int) bool {
	return age >= 18 // результат сравнения — уже true или false
}
```

Если у соседних параметров одинаковый тип, его можно написать один раз: `func Add(a, b int) int`.

Значения при вызове подставляются **по порядку**: в `Add(2, 5)` в `a` попадёт 2, в `b` — 5.

## Условия и циклы внутри функций

Внутри функции можно писать всё, что вы уже умеете:

```go
func Abs(n int) int {
	if n < 0 {
		return -n
	}
	return n
}
```

При `n = -5` сработает первый `return`, и функция закончится. При `n = 5` условие ложно, выполнение дойдёт до второго `return`.

> **Важно:** функция, которая обещает результат, должна вернуть его **на любом пути**. Если `return` есть только внутри `if`, компилятор скажет `missing return` — «а что возвращать, когда условие не выполнилось?».

## Напечатать и вернуть — не одно и то же

Это самая частая путаница у начинающих.

```go
func DoubleA(x int) int {
	return x * 2 // возвращает результат — им можно пользоваться дальше
}

func DoubleB(x int) {
	fmt.Println(x * 2) // только печатает на экран; результата у функции нет
}
```

`DoubleA(4) + 1` — это 9. А с `DoubleB` так не получится: она ничего не возвращает. Печать показывает значение **человеку**, `return` отдаёт его **программе**.

## main — тоже функция

Теперь понятно, что такое `func main() { … }`: функция без параметров и без результата, которую Go вызывает сам при запуске программы. Свои функции пишут рядом с ней — выше или ниже, порядок не важен:

```go
package main

import "fmt"

func Double(x int) int {
	return x * 2
}

func main() {
	fmt.Println(Double(21))
}
```

Переменные, созданные внутри функции, существуют только в ней. Переменная `x` из `Double` не видна в `main`, и наоборот.

## Как теперь проверяются задачи

Начиная с этого урока и во всём остальном курсе задачи выглядят так: «Реализуйте функцию `Square(x int) int`…». Проверка работает иначе, чем раньше:

- Тесты **сами вызывают** вашу функцию с разными аргументами и сравнивают то, что она **вернула**, с правильным ответом.
- Поэтому имя функции, параметры и тип результата менять нельзя — иначе тесты её не найдут.
- Результат нужно именно **вернуть** через `return`. Печатать его внутри функции не нужно.
- Функция `main` в заготовке — для ваших экспериментов: меняйте в ней вызовы и нажимайте «Запустить», чтобы посмотреть, что возвращает функция.

Если тест не прошёл, в сообщении видно, что именно не так:

```text
--- FAIL: TestSquare (0.00s)
    checker_test.go:9: Square(3) = 6, а должно быть 9
```

Читается просто: функцию вызвали с аргументом 3, она вернула 6, а ожидалось 9. Остаётся понять почему — и поправить.

@@ quiz
@@ q
Что напечатает программа?
```go
func Mystery(a, b int) int {
	return a*b + 1
}

func main() {
	fmt.Println(Mystery(3, 4))
}
```
- [ ] `12`
- [x] `13`
- [ ] `8`
- [ ] Ничего: функция только возвращает значение
@@ explain
При вызове `Mystery(3, 4)` в `a` попадает 3, в `b` — 4. Функция возвращает 3 × 4 + 1 = 13, и `Println` в `main` печатает это значение.

@@ q
Чем `return x` отличается от `fmt.Println(x)`?
- [ ] Ничем, оба показывают результат
- [x] `return` отдаёт значение тому, кто вызвал функцию; `Println` только печатает его на экран
- [ ] `return` печатает значение и завершает программу
- [ ] `Println` быстрее
@@ explain
Возвращённое значение можно положить в переменную, сравнить, использовать в вычислениях. Напечатанное — просто появилось на экране, программа с ним дальше работать не может. Тесты в задачах проверяют именно возвращённое значение.

@@ q
Что означает запись `func Check(age int) bool`?
- [ ] Функция `Check` принимает значение типа `bool` и возвращает целое число
- [x] Функция `Check` принимает целое число `age` и возвращает `true` или `false`
- [ ] Функция `age` проверяет значение `Check`
- [ ] Это вызов функции `Check`
@@ explain
После слова `func` идёт имя функции, в скобках — параметры с типами, после скобок — тип результата. `bool` — это тип значений «да/нет»: `true` или `false`.

@@ task square | Квадрат числа | xp=30
Реализуйте функцию `Square(x int) int`, которая возвращает квадрат числа — число, умноженное само на себя.

Например, `Square(3)` должно вернуть `9`, а `Square(-4)` — `16`.

Сейчас функция всегда возвращает 0. В `main` уже есть вызов для проверки — нажмите «Запустить» и посмотрите, что печатается.
@@ hint
Квадрат числа — это `x * x`. Его нужно вернуть: `return …`.
@@ hint
Тело функции — одна строка: `return x * x`.

package main

import "fmt"

func Square(x int) int {
	// Верните квадрат числа x
	return 0

func main() {

package main

@@ task max | Большее из двух | xp=30
Реализуйте функцию `Max(a, b int) int`, которая возвращает большее из двух чисел. Если числа равны, верните любое из них.

Например, `Max(3, 8)` → `8`, `Max(5, -2)` → `5`.
@@ hint
Сравните числа через `if`: если `a` больше `b`, верните `a`.
@@ hint
`if a > b { return a }`, а после условия — `return b`. Второй `return` выполнится, только если первый не сработал.
@@ starter
package main

import "fmt"

func Max(a, b int) int {
	// Верните большее из чисел a и b
	return 0
}

func main() {
	fmt.Println(Max(3, 8)) // должно получиться 8
}
@@ solution
package main

import "fmt"

func Max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func main() {
	fmt.Println(Max(3, 8)) // должно получиться 8
}
@@ test
package main

import "testing"

func TestMax(t *testing.T) {
	cases := [][3]int{{3, 8, 8}, {8, 3, 8}, {5, -2, 5}, {-7, -3, -3}, {4, 4, 4}, {0, 100, 100}}
	for _, c := range cases {
		if got := Max(c[0], c[1]); got != c[2] {
			t.Errorf("Max(%d, %d) = %d, а должно быть %d", c[0], c[1], got, c[2])
		}
	}
}

@@ task sumto | Сумма до N | xp=30
Реализуйте функцию `SumTo(n int) int`, которая возвращает сумму всех целых чисел от 1 до `n` включительно.

Например, `SumTo(4)` → `10` (1 + 2 + 3 + 4), `SumTo(1)` → `1`. Для `n`, меньшего 1, верните `0`.

Это та же задача, что в прошлом уроке, только теперь результат нужно не напечатать, а **вернуть**.
@@ hint
Внутри функции заведите `sum := 0`, в цикле от 1 до `n` прибавляйте счётчик, а после цикла — `return sum`.
@@ hint
`sum := 0`, затем `for i := 1; i <= n; i++ { sum += i }`, затем `return sum`. При `n` меньше 1 цикл не выполнится ни разу, и вернётся 0 — отдельная проверка не нужна.
@@ starter
package main

import "fmt"

func SumTo(n int) int {
	// Верните сумму чисел от 1 до n
	return 0
}

func main() {
	fmt.Println(SumTo(4)) // должно получиться 10
}
@@ solution
package main

import "fmt"

func SumTo(n int) int {
	sum := 0
	for i := 1; i <= n; i++ {
		sum += i
	}
	return sum
}

func main() {
	fmt.Println(SumTo(4)) // должно получиться 10
}
@@ test
package main

import "testing"

func TestSumTo(t *testing.T) {
	cases := [][2]int{{4, 10}, {1, 1}, {10, 55}, {100, 5050}, {0, 0}, {-5, 0}}
	for _, c := range cases {
		if got := SumTo(c[0]); got != c[1] {
			t.Errorf("SumTo(%d) = %d, а должно быть %d", c[0], got, c[1])
		}
	}
}
