## Программа умеет выбирать

До сих пор программа выполняла все строки подряд. Но обычно действие зависит от ситуации: если пароль верный — впустить, иначе — отказать. Для этого есть **условия**.

```go
age := 20
if age >= 18 {
	fmt.Println("Доступ разрешён")
}
```

Читается почти как по-русски: «**если** `age` больше или равно 18, выполни то, что в фигурных скобках». Если условие не выполняется, строки внутри скобок просто пропускаются.

## Сравнения

Условие — это вопрос, на который можно ответить только «да» или «нет»:

| Запись | Значение |
|---|---|
| `a == b` | равно |
| `a != b` | не равно |
| `a < b`, `a > b` | меньше, больше |
| `a <= b`, `a >= b` | меньше или равно, больше или равно |

> **Ловушка:** «равно» в условии — это **два** знака: `==`. Один знак `=` означает «положи значение в переменную». Запись `if age = 18` — ошибка компиляции.

Ответ на такой вопрос — значение типа `bool`: `true` («да», истина) или `false` («нет», ложь). Его можно даже напечатать:

```go
fmt.Println(5 > 3)  // true
fmt.Println(5 == 3) // false
```

## Иначе: else

```go
if age >= 18 {
	fmt.Println("Доступ разрешён")
} else {
	fmt.Println("Доступ запрещён")
}
```

Выполнится ровно одна из двух веток: первая, если условие истинно, вторая — если ложно.

> **Важно:** `else` пишется на той же строке, что и закрывающая скобка: `} else {`. Перенос `else` на новую строку — ошибка компиляции.

## Несколько вариантов: else if

```go
temp := 15
if temp < 0 {
	fmt.Println("Мороз")
} else if temp < 20 {
	fmt.Println("Прохладно")
} else {
	fmt.Println("Тепло")
}
```

Условия проверяются **сверху вниз**, и выполняется первая подошедшая ветка — остальные пропускаются. Здесь `temp` равно 15: первое условие ложно, второе истинно — печатается `Прохладно`, до `else` дело не доходит.

Поэтому важен порядок. Ко второй проверке мы уже знаем, что `temp` не меньше нуля, и писать «от 0 до 20» целиком не нужно.

## И, или, не

Условия можно объединять:

| Запись | Значение | Истинно, когда |
|---|---|---|
| `a && b` | «и» | верны **оба** условия |
| `a \|\| b` | «или» | верно **хотя бы одно** |
| `!a` | «не» | условие `a` ложно |

```go
age := 25
hasTicket := true

if age >= 18 && hasTicket {
	fmt.Println("Проходите")
}

day := "сб"
if day == "сб" || day == "вс" {
	fmt.Println("Выходной")
}
```

## Чётное или нечётное

Остаток от деления `%` из прошлого урока часто встречается в условиях. Число чётное, если при делении на 2 остаток равен нулю:

```go
n := 14
if n%2 == 0 {
	fmt.Println("чётное")
} else {
	fmt.Println("нечётное")
}
```

Точно так же проверяют «делится ли на 3»: `n%3 == 0`.

## Отступы

Строки внутри фигурных скобок принято сдвигать вправо клавишей `Tab` — так сразу видно, что к чему относится. Редактор на сайте делает отступ сам, когда вы нажимаете `Enter` после `{`.

@@ q
Что напечатает программа?
```go
x := 7
if x > 10 {
	fmt.Println("большое")
} else if x > 5 {
	fmt.Println("среднее")
} else {
	fmt.Println("маленькое")
}
```
- [ ] `большое`
- [x] `среднее`
- [ ] `маленькое`
- [ ] `среднее`, а затем `маленькое`
@@ explain
Условия проверяются сверху вниз. `7 > 10` — ложь, идём дальше. `7 > 5` — истина: печатается `среднее`, и на этом всё — остальные ветки пропускаются.

@@ q
Какая запись проверяет, что `x` равен 5?
- [ ] `if x = 5`
- [x] `if x == 5`
- [ ] `if x := 5`
- [ ] `if x equals 5`
@@ explain
Сравнение на равенство — это два знака: `==`. Один знак `=` кладёт значение в переменную, а не сравнивает.

@@ q
Переменная `age` равна 15. Чему равно `age >= 7 && age < 14`?
- [ ] `true`
- [x] `false`
- [ ] `15`
- [ ] Это ошибка: нельзя писать два условия сразу
@@ explain
`&&` — это «и»: результат истинен, только если верны оба условия. `15 >= 7` — истина, но `15 < 14` — ложь, поэтому всё выражение ложно.

@@ task sign | Знак числа | xp=30
В переменной `n` записано целое число. Напечатайте одно слово:

- `положительное`, если число больше нуля;
- `отрицательное`, если меньше нуля;
- `ноль`, если равно нулю.

Тесты проверят программу с разными значениями `n`.
@@ hint
Вариантов три, значит, нужна цепочка `if … else if … else`.
@@ hint
`if n > 0 { … } else if n < 0 { … } else { … }` — в последнюю ветку попадает единственный оставшийся случай, ноль.
@@ starter
package main

import "fmt"

// Тесты будут подставлять сюда другие числа.
var n = -7

func main() {
	// Сейчас программа всегда печатает одно и то же — добавьте условия
	fmt.Println("положительное")
}
@@ solution
package main

import "fmt"

// Тесты будут подставлять сюда другие числа.
var n = -7

func main() {
	if n > 0 {
		fmt.Println("положительное")
	} else if n < 0 {
		fmt.Println("отрицательное")
	} else {
		fmt.Println("ноль")
	}
}

package main

import (
	"io"
	"os"
	"strings"
	"testing"
)

func runMain(t *testing.T) string {
	t.Helper()
	old := os.Stdout
	r, w, err := os.Pipe()
	if err != nil {
		t.Fatal(err)
	}
	os.Stdout = w
	func() {
		defer func() { os.Stdout = old; w.Close() }()
		main()
	}()
	b, _ := io.ReadAll(r)
	lines := strings.Split(strings.ReplaceAll(string(b), "\r\n", "\n"), "\n")
	for i := range lines {
		lines[i] = strings.TrimRight(lines[i], " \t")
	}
	return strings.TrimRight(strings.Join(lines, "\n"), "\n")
}

func TestSign(t *testing.T) {
	cases := map[int]string{-7: "отрицательное", 5: "положительное", 0: "ноль", 1: "положительное", -1: "отрицательное", 1000: "положительное"}
	for _, v := range []int{-7, 5, 0, 1, -1, 1000} {
		n = v
		if got, want := runMain(t), cases[v]; got != want {
			t.Errorf("при n = %d программа напечатала:\n%s\n\nа нужно:\n%s\n", v, got, want)
		}
	}
}

@@ task leap | Високосный год | xp=30
В переменной `year` записан год. Напечатайте `високосный` или `обычный`.

Год високосный, если он делится на 4, **но не** делится на 100. Исключение: годы, которые делятся на 400, тоже високосные.

Примеры: 2024 — високосный, 2023 — обычный, 1900 — обычный (делится на 100, но не на 400), 2000 — високосный (делится на 400).
@@ hint
«Делится на 4» записывается как `year%4 == 0`, «не делится на 100» — `year%100 != 0`. Объединяйте условия через `&&` («и») и `||` («или»).
@@ hint
Условие целиком: `year%400 == 0 || (year%4 == 0 && year%100 != 0)`. Скобки показывают, что сначала вычисляется «и», а потом «или».
@@ starter
package main

import "fmt"

// Тесты будут подставлять сюда другие годы.
var year = 2024

func main() {
	// Сейчас любой год считается обычным — добавьте проверку
	fmt.Println("обычный")
}
@@ solution
package main

import "fmt"

// Тесты будут подставлять сюда другие годы.
var year = 2024

func main() {
	if year%400 == 0 || (year%4 == 0 && year%100 != 0) {
		fmt.Println("високосный")
	} else {
		fmt.Println("обычный")
	}
}

func TestLeap(t *testing.T) {
	leap := map[int]bool{2024: true, 2023: false, 1900: false, 2000: true, 2100: false, 1996: true, 2022: false, 2400: true}
