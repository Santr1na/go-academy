## Одна переменная — много значений

Оценки за неделю, цены товаров в корзине, имена гостей — часто данных много, и заводить отдельную переменную под каждое значение неудобно. Для этого есть **срез** (по-английски *slice*) — упорядоченный список значений одного типа.

```go
scores := []int{5, 3, 4}
fmt.Println(scores) // [5 3 4]
```

Запись `[]int{5, 3, 4}` читается так: «срез целых чисел с элементами 5, 3 и 4». Квадратные скобки перед типом означают «список таких значений»: `[]int` — список целых, `[]string` — список строк.

```go
names := []string{"Аня", "Борис", "Вера"}
```

## Индексы: счёт идёт с нуля

У каждого элемента есть номер — **индекс**. Нумерация начинается **с нуля**:

```go
names := []string{"Аня", "Борис", "Вера"}
//                  0       1        2

fmt.Println(names[0]) // Аня
fmt.Println(names[2]) // Вера

names[1] = "Богдан"   // элемент можно заменить
fmt.Println(names)    // [Аня Богдан Вера]
```

К счёту с нуля быстро привыкаешь: первый элемент — `[0]`, второй — `[1]` и так далее.

## Длина: len

Функция `len` возвращает количество элементов:

```go
fmt.Println(len(names)) // 3
```

Раз счёт идёт с нуля, **последний** элемент имеет индекс `len(names) - 1`. В срезе из трёх элементов это индекс 2.

> **Ловушка:** обращение к несуществующему элементу — например, `names[3]` в срезе из трёх элементов — останавливает программу с ошибкой `index out of range [3] with length 3`. Она читается так: «попросили элемент с индексом 3, а элементов всего 3» — то есть индексы есть только 0, 1 и 2.

## Добавление: append

```go
nums := []int{1, 2}
nums = append(nums, 3)
fmt.Println(nums)      // [1 2 3]
fmt.Println(len(nums)) // 3
```

Обратите внимание на форму записи: результат `append` нужно **положить обратно** в ту же переменную. Просто `append(nums, 3)` без присваивания ничего не изменит (и не скомпилируется).

Срез можно создать пустым и наполнять постепенно:

```go
var result []int // пустой срез целых чисел
result = append(result, 10)
result = append(result, 20)
fmt.Println(result) // [10 20]
```

## Обход среза циклом

Самое частое действие со срезом — пройти по всем элементам. Способ первый — цикл со счётчиком-индексом:

```go
nums := []int{4, 8, 15}
for i := 0; i < len(nums); i++ {
	fmt.Println(nums[i])
}
```

Счётчик идёт от 0, а условие — строго `i < len(nums)`: при трёх элементах `i` принимает значения 0, 1, 2.

Способ второй, более короткий и удобный, — `range`:

```go
for i, v := range nums {
	fmt.Println(i, v) // 0 4, затем 1 8, затем 2 15
}
```

На каждом шаге `range` кладёт в `i` индекс, а в `v` — сам элемент. Имена переменных можете выбрать любые.

Индекс нужен не всегда. Но Go не разрешает оставлять переменные неиспользованными, поэтому на месте ненужной ставят прочерк `_`:

```go
sum := 0
for _, v := range nums {
	sum += v
}
fmt.Println(sum) // 27
```

## Срезы и функции

Срез можно передать в функцию и вернуть из неё — тип записывается так же, с квадратными скобками:

```go
// Count возвращает, сколько раз число x встречается в срезе nums.
func Count(nums []int, x int) int {
	count := 0
	for _, v := range nums {
		if v == x {
			count++
		}
	}
	return count
}

func main() {
	fmt.Println(Count([]int{1, 2, 1, 3, 1}, 1)) // 3
}
```

Посмотрите на эту функцию внимательно: в ней сошлось всё, что вы изучили, — переменная-накопитель, цикл, условие, функция с параметрами и результатом. Именно из таких кирпичиков строится любая программа.

@@ q
Что напечатает программа?
```go
nums := []int{7, 7, 7}
nums = append(nums, 1)
nums = append(nums, 2)
fmt.Println(len(nums))
```
- [ ] `3`
- [ ] `4`
- [x] `5`
- [ ] `24`
@@ explain
Сначала в срезе три элемента. Каждый `append` добавляет один элемент в конец — получается 5. `len` возвращает количество элементов, а не их сумму.

@@ q
В срезе `data` пять элементов. Какое обращение остановит программу с ошибкой `index out of range`?
- [ ] `data[0]`
- [ ] `data[4]`
- [x] `data[5]`
- [ ] `data[len(data)-1]`
@@ explain
В срезе из пяти элементов индексы — от 0 до 4. Элемента с индексом 5 нет. Последний элемент — `data[4]`, он же `data[len(data)-1]`.

@@ q
Зачем в записи `for _, v := range nums` стоит прочерк `_`?
- [ ] Это опечатка, прочерк не нужен
- [x] На этом месте `range` выдаёт индекс; прочерк означает «он мне не нужен»
- [ ] Прочерк означает «перебирать в обратном порядке»
- [ ] Так обозначается пустой срез
@@ explain
`range` на каждом шаге выдаёт два значения — индекс и элемент. Если индекс не используется, его «выбрасывают» в `_`, иначе компилятор сообщит о неиспользуемой переменной.

@@ solution
package main

import "fmt"

func Sum(nums []int) int {
	sum := 0
	for _, v := range nums {
		sum += v
	}
	return sum
}

func main() {
	fmt.Println(Sum([]int{4, 8, 15})) // должно получиться 27
}

package main

import "fmt"

func MaxOf(nums []int) int {
	if len(nums) == 0 {
		return 0
	}
	best := nums[0]
	for _, v := range nums {
		if v > best {
			best = v
		}
	}
	return best
}

func main() {
	fmt.Println(MaxOf([]int{3, 9, 2})) // должно получиться 9
}

package main

import "fmt"

func Evens(nums []int) []int {
	var result []int
	for _, v := range nums {
		if v%2 == 0 {
			result = append(result, v)
		}
	}
	return result
}

func main() {
	fmt.Println(Evens([]int{1, 2, 3, 4, 6})) // должно получиться [2 4 6]
}
@@ test
package main

import "testing"

func same(a, b []int) bool {
	if len(a) != len(b) {
		return false
	}
	for i := range a {
		if a[i] != b[i] {
			return false
		}
	}
	return true
}

func TestEvens(t *testing.T) {
	cases := []struct {
		nums, want []int
	}{
		{[]int{1, 2, 3, 4, 6}, []int{2, 4, 6}},
		{[]int{2, 2, 2}, []int{2, 2, 2}},
		{[]int{1, 3, 5}, []int{}},
		{[]int{0, -2, -3, 10}, []int{0, -2, 10}},
		{[]int{}, []int{}},
	}
	for _, c := range cases {
		got := Evens(c.nums)
		if !same(got, c.want) {
			t.Errorf("Evens(%v) = %v, а должно быть %v", c.nums, got, c.want)
		}
	}
}
