## Зачем нужны переменные

Программе постоянно нужно что-то помнить: возраст пользователя, цену товара, сколько осталось попыток. Для этого есть **переменные**.

Переменная — это коробка с подписью. На коробке написано **имя**, внутри лежит **значение**:

```go
age := 25
fmt.Println(age) // 25
```

Запись `age := 25` читается так: «создай переменную `age` и положи в неё 25». Дальше в программе слово `age` означает «то, что сейчас лежит в коробке».

> **Важно:** имя переменной пишется **без кавычек**. `fmt.Println(age)` напечатает `25`, а `fmt.Println("age")` — слово `age`.

## Создать и изменить — разные действия

```go
score := 10 // := создаёт новую переменную
score = 15  // =  кладёт новое значение в уже существующую
fmt.Println(score) // 15
```

- `:=` — «создай переменную». Для каждого имени используется один раз.
- `=` — «замени значение». Старое значение при этом пропадает.

Знак `=` в программировании — не «равно» из математики, а команда «положи то, что справа, в переменную слева».

## Имена

Имя может состоять из латинских букв, цифр и `_`, но не может начинаться с цифры. Называйте переменные так, чтобы было понятно, что внутри: `price`, `userName`, `totalSeconds`. Имя из нескольких слов пишут слитно, каждое следующее слово — с заглавной буквы.

## Числа и арифметика

```go
a := 7
b := 2
fmt.Println(a + b) // 9   сложение
fmt.Println(a - b) // 5   вычитание
fmt.Println(a * b) // 14  умножение
fmt.Println(a / b) // 3   деление — внимание!
fmt.Println(a % b) // 1   остаток от деления
```

Почему `7 / 2` — это `3`, а не `3.5`? Потому что `7` и `2` — **целые числа**, и результат тоже будет целым: дробная часть просто отбрасывается. Это называется **целочисленное деление**.

Оператор `%` даёт **остаток**: 7 делится на 2 «по 3 раза, и 1 остаётся». Пара `/` и `%` очень полезна: например, 135 минут — это `135 / 60 = 2` часа и `135 % 60 = 15` минут.

Скобки работают как в математике: `2 * (3 + 4)` — это 14, а `2 * 3 + 4` — это 10.

## Дробные числа

Если нужна дробная часть, используйте числа с точкой:

```go
price := 99.5
fmt.Println(price * 2) // 199
fmt.Println(7.0 / 2)   // 3.5
```

## Текст (строки)

Текст в кавычках тоже можно хранить в переменной. Строки склеиваются плюсом:

```go
name := "Аня"
greeting := "Привет, " + name + "!"
fmt.Println(greeting) // Привет, Аня!
```

Обратите внимание на пробел внутри кавычек после запятой: плюс склеивает строки вплотную, сам пробелы не добавляет.

А вот `Println` с несколькими значениями через запятую пробелы ставит сам:

```go
fmt.Println("Возраст:", age, "лет") // Возраст: 25 лет
```

## У каждого значения есть тип

`25` — целое число, `99.5` — дробное, `"Аня"` — строка. Это разные **типы**, и Go не даёт их смешивать:

```go
age := 25
age = "двадцать пять" // ошибка: в переменную для чисел нельзя положить текст
```

По той же причине `"2" + "3"` — это не 5, а строка `"23"`: склеились два текста.

Названия основных типов пригодятся уже скоро:

| Тип | Что хранит | Примеры |
|---|---|---|
| `int` | целые числа | `0`, `42`, `-7` |
| `float64` | дробные числа | `3.14`, `-0.5` |
| `string` | текст | `"Привет"` |
| `bool` | «да» или «нет» | `true`, `false` |

## Обновление переменной

Новое значение часто вычисляют из старого:

```go
count := 5
count = count + 1 // взяли 5, прибавили 1, положили обратно: 6
count += 10       // то же самое, но короче: 16
count++           // прибавить ровно 1: 17
```

## Go следит за порядком

Если создать переменную внутри `main` и нигде её не использовать, программа не скомпилируется: `declared and not used`. Это не придирка — так Go помогает не оставлять в коде мусор и опечатки.

## Исходные данные в задачах

В задачах этого модуля исходные данные записаны **над** функцией `main`, вот так:

```go
var width = 37

func main() {
	fmt.Println(width * 2)
}
```

`var width = 37` — это то же самое, что `width := 37`, просто полная форма записи: вне функций разрешена только она. Сделано это для проверки: тесты подставляют в такие переменные разные числа и смотрят, правильно ли считает ваша программа. Поэтому **не переименовывайте их** и не вписывайте готовый ответ числом — используйте переменные по имени.

@@ quiz
@@ q
Что напечатает программа?
```go
x := 10
x = x + 5
x = x * 2
fmt.Println(x)
```
- [ ] `10`
- [ ] `25`
- [x] `30`
- [ ] `20`
@@ explain
Идём по строкам: сначала в `x` лежит 10, затем 10 + 5 = 15, затем 15 × 2 = 30. Каждое присваивание заменяет прежнее значение.

@@ q
Чему равно `17 / 5` и `17 % 5`, если оба числа целые?
- [ ] `3.4` и `0`
- [x] `3` и `2`
- [ ] `3` и `4`
- [ ] `4` и `2`
@@ explain
При делении целых чисел дробная часть отбрасывается: 17 / 5 = 3. Остаток — то, что «не поделилось»: 17 − 3 × 5 = 2.

@@ q
Что напечатает `fmt.Println("2" + "3")`?
- [ ] `5`
- [x] `23`
- [ ] `2 3`
- [ ] Будет ошибка компиляции
@@ explain
В кавычках — строки, а не числа. Плюс между строками склеивает их вплотную: получится текст `23`.

@@ q
Чем `:=` отличается от `=`?
- [ ] Ничем, это одно и то же
- [x] `:=` создаёт новую переменную, `=` меняет значение уже существующей
- [ ] `:=` — для чисел, `=` — для текста
- [ ] `=` создаёт переменную, `:=` сравнивает два значения
@@ explain
`age := 25` создаёт переменную `age`. Чтобы потом положить в неё другое значение, пишут `age = 26`. Повторное `age := 26` в том же месте вызовет ошибку: такая переменная уже есть.

@@ task rect | Площадь и периметр | xp=30
Над функцией `main` заданы ширина и высота прямоугольника — переменные `width` и `height`. Вычислите площадь и периметр и напечатайте их в две строки. Для `width = 37` и `height = 58` должно получиться:

```
Площадь: 2146
Периметр: 190
```

Площадь — это ширина × высота, периметр — 2 × (ширина + высота).

Тесты подставят и другие значения ширины и высоты, поэтому считайте через переменные, а не вписывайте готовые числа.
@@ hint
Создайте переменную для результата: `area := width * height`. Затем напечатайте подпись и значение через запятую: `fmt.Println("Площадь:", area)`.
@@ hint
Для периметра не забудьте скобки: `perimeter := 2 * (width + height)`. Не создавайте внутри `main` новые переменные с именами `width` и `height` — пользуйтесь теми, что объявлены сверху.
@@ starter
package main

import "fmt"

// Исходные данные. Тесты будут подставлять сюда другие числа.
var width = 37
var height = 58

func main() {
	// Вычислите площадь и периметр и напечатайте их вместо нулей
	fmt.Println("Площадь:", 0)
	fmt.Println("Периметр:", 0)
}
@@ solution
package main

import "fmt"

// Исходные данные. Тесты будут подставлять сюда другие числа.
var width = 37
var height = 58

func main() {
	area := width * height
	perimeter := 2 * (width + height)
	fmt.Println("Площадь:", area)
	fmt.Println("Периметр:", perimeter)
}
@@ test
package main

import (
	"fmt"
	"io"
	"os"
	"strings"
	"testing"
)

func runMain(t *testing.T) string {
	t.Helper()
	old := os.Stdout
	r, w, err := os.Pipe()
	if err != nil {
		t.Fatal(err)
	}
	os.Stdout = w
	func() {
		defer func() { os.Stdout = old; w.Close() }()
		main()
	}()
	b, _ := io.ReadAll(r)
	lines := strings.Split(strings.ReplaceAll(string(b), "\r\n", "\n"), "\n")
	for i := range lines {
		lines[i] = strings.TrimRight(lines[i], " \t")
	}
	return strings.TrimRight(strings.Join(lines, "\n"), "\n")
}

func TestRect(t *testing.T) {
	for _, c := range [][2]int{{37, 58}, {1, 1}, {10, 3}, {120, 45}} {
		width, height = c[0], c[1]
		want := fmt.Sprintf("Площадь: %d\nПериметр: %d", c[0]*c[1], 2*(c[0]+c[1]))
		if got := runMain(t); got != want {
			t.Errorf("при width = %d и height = %d программа напечатала:\n%s\n\nа нужно:\n%s\n", c[0], c[1], got, want)
		}
	}
}

@@ task clock | Секунды в часы, минуты и секунды | xp=30
В переменной `total` записано время в секундах. Переведите его в часы, минуты и секунды и напечатайте одной строкой. Для `total = 7384`:

```
2 ч 3 мин 4 с
```

Проверка: 2 × 3600 + 3 × 60 + 4 = 7384.
@@ hint
В часе 3600 секунд. Целых часов — `total / 3600`. А `total % 3600` — это секунды, которые остались после вычета целых часов.
@@ hint
`hours := total / 3600`, `minutes := total % 3600 / 60`, `seconds := total % 60`. Печать: `fmt.Println(hours, "ч", minutes, "мин", seconds, "с")` — пробелы `Println` расставит сам.

	// Вычислите часы, минуты и секунды

}

@@ task greeting | Приветствие | xp=30


Следите за пробелами и знаками: после имени сразу идёт восклицательный знак, без пробела.

func TestGreeting(t *testing.T) {
