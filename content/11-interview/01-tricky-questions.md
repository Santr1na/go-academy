## Как отвечать на вопросы «что выведет код?»

На собеседовании важен не только ответ, но и **рассуждение**. Проговаривайте:

1. какие значения копируются, а какие разделяют память (массивы vs срезы, структуры vs указатели);
2. когда вычисляются выражения (аргументы `defer`, правая часть присваивания, `range` по массиву копирует его);
3. что знает компилятор, а что — только runtime (паники, nil-интерфейсы);
4. какая версия Go: семантика переменной цикла изменилась в 1.22.

## Шпаргалка ловушек

| Тема | Ловушка |
|---|---|
| Срезы | `append` может писать в общий массив; подсрез держит весь массив в памяти |
| Map | порядок обхода случаен; запись в nil-map — паника; значения неадресуемы |
| Строки | `len` — байты; `s[i]` — байт; `range` — руны с байтовыми индексами |
| Интерфейсы | интерфейс с nil-указателем ≠ nil; сравнение несравнимых — паника |
| defer | LIFO; аргументы вычисляются сразу; может менять именованные результаты |
| Замыкания | захватывают переменную, а не значение |
| Каналы | закрытый → нулевые значения; отправка в закрытый → паника; nil → блокировка |
| Горутины | main не ждёт; паника в горутине роняет программу |
| Методы | value receiver работает с копией; method set `T` не содержит методов `*T` |
| range | по массиву — копия массива; по каналу — до закрытия |

## Пример разбора

```go
func main() {
	a := [3]int{1, 2, 3}
	for i, v := range a {
		if i == 0 {
			a[1], a[2] = 20, 30
		}
		fmt.Print(v, " ")
	}
}
```

Ответ: `1 2 3`. `range` по **массиву** итерирует по его копии, сделанной до начала цикла. Если бы это был срез (`a := []int{...}`) или `range &a`, вывод был бы `1 20 30`.

@@ quiz
@@ q
Что выведет код?
```go
s := []int{1, 2, 3}
t := s[:2]
t = append(t, 4)
s = append(s, 5)
fmt.Println(s, t)
```
- [ ] `[1 2 3 5] [1 2 4]`
- [x] `[1 2 4 5] [1 2 4]`
- [ ] `[1 2 3 5] [1 2 3 4]`
@@ explain
`t` (len 2, cap 3) делит массив с `s`. `append(t, 4)` пишет 4 в `s[2]`. Затем у `s` (len 3, cap 3) нет места — `append` создаёт новый массив `[1 2 4 5]`. `t` остаётся на старом массиве: `[1 2 4]`.

@@ q
Что выведет код?
```go
var m map[string]int
fmt.Println(m["a"], len(m))
delete(m, "a")
fmt.Println("ok")
```
- [ ] Паника на чтении
- [ ] Паника на delete
- [x] `0 0`, затем `ok`
@@ explain
Чтение, `len` и `delete` для nil-map безопасны. Паникует только запись.

@@ q
Что выведет код?
```go
type T struct{}
func (t *T) Error() string { return "T" }

func get() error {
	var t *T
	return t
}

func main() {
	err := get()
	fmt.Println(err == nil, err != nil)
}
```
- [ ] `true false`
- [x] `false true`
- [ ] Паника
@@ explain
Классический nil-интерфейс: в `error` лежит тип `*T` с nil-значением, поэтому интерфейс не равен nil.

@@ q
Что выведет код?
```go
func f() (x int) {
	defer func() { x *= 2 }()
	x = 1
	return x + 1
}
fmt.Println(f())
```
- [ ] 2
- [x] 4
- [ ] 3
@@ explain
`return x + 1` присваивает результату x = 2, затем defer удваивает его до 4.

@@ q
Что выведет код?
```go
ch := make(chan int, 1)
ch <- 1
close(ch)
v1, ok1 := <-ch
v2, ok2 := <-ch
fmt.Println(v1, ok1, v2, ok2)
```
- [ ] Паника: чтение из закрытого канала
- [x] `1 true 0 false`
- [ ] `1 false 0 false`
@@ explain
Сначала из закрытого канала дочитывается буферизованное значение (`ok == true`), затем возвращаются нулевые значения с `ok == false`.

@@ q
Что выведет код?
```go
s := "привет"
fmt.Println(len(s), s[1], string(s[0:2]))
```
- [ ] `6 р пр`
- [x] `12 191 п`
- [ ] `12 р п`
@@ explain
`len` — 12 байт. `s[1]` — второй байт буквы «п» (число 191). `s[0:2]` — первые два байта, т. е. ровно «п».

@@ q
Что произойдёт?
```go
func main() {
	var wg sync.WaitGroup
	for i := 0; i < 3; i++ {
		go func() {
			wg.Add(1)
			defer wg.Done()
			fmt.Print(i)
		}()
	}
	wg.Wait()
}
```
- [ ] Всегда выведет 3 числа
- [x] Может ничего не вывести: `Wait` может вернуться до того, как горутины вызовут `Add`
- [ ] Deadlock
@@ explain
`Add` должен вызываться до запуска горутины. Здесь `Wait` может увидеть счётчик 0 и вернуться сразу — программа завершится.

@@ q
Что выведет код (Go 1.22+)?
```go
var out []*int
for i := range 3 {
	out = append(out, &i)
}
fmt.Println(*out[0], *out[1], *out[2])
```
- [ ] `2 2 2`
- [ ] `3 3 3`
- [x] `0 1 2`
@@ explain
С Go 1.22 у каждой итерации своя переменная `i`, поэтому указатели разные. До 1.22 ответ был бы `2 2 2` (одна переменная, последнее значение 2).

@@ q
Что выведет код?
```go
type P struct{ N int }
ps := []P{{1}, {2}}
for _, p := range ps {
	p.N *= 10
}
m := map[string]*P{"a": {1}}
m["a"].N = 5
fmt.Println(ps, m["a"].N)
```
- [ ] `[{10} {20}] 5`
- [x] `[{1} {2}] 5`
- [ ] Ошибка компиляции: `m["a"].N = 5`
@@ explain
`p` — копия, срез не меняется. В map хранятся указатели, поэтому `m["a"].N = 5` меняет объект по указателю — это допустимо (недопустимо было бы для `map[string]P`).

@@ q
Что выведет код?
```go
x := []int{1, 2, 3}
y := x
y = append(y[:1], y[2:]...)
fmt.Println(x, y)
```
- [ ] `[1 2 3] [1 3]`
- [x] `[1 3 3] [1 3]`
- [ ] `[1 3] [1 3]`
@@ explain
Удаление через `append` сдвигает элементы в **том же** массиве: `x` видит `[1 3 3]` (длина x не изменилась), а `y` имеет длину 2.

@@ q
Что выведет код?
```go
for i := 0; i < 3; i++ {
	defer func(n int) { fmt.Print(n) }(i)
}
```
- [ ] `012`
- [x] `210`
- [ ] `333`
@@ explain
Аргумент `n` вычисляется в момент `defer`, вызовы выполняются в обратном порядке: 2, 1, 0.

@@ q
Какой из вариантов приведёт к панике?
- [ ] `var s []int; s = append(s, 1)`
- [ ] `var m map[string]int; _ = m["x"]`
- [x] `var ch chan int; close(ch)`
- [ ] `var p *int; fmt.Println(p == nil)`
@@ explain
Закрытие nil-канала — паника. Остальные операции безопасны.

@@ task brackets | Сбалансированные скобки | xp=60 interview
Реализуйте `IsBalanced(s string) bool` — проверка, что скобки `()`, `[]`, `{}` в строке сбалансированы и правильно вложены. Остальные символы игнорируются.

- `"{[()()]}"` → `true`
- `"([)]"` → `false`
- `"((("` → `false`
- `"func() { return a[i] }"` → `true`
- `""` → `true`

Сложность O(n), используйте срез как стек.
@@ hint
Открывающую скобку кладите в стек. На закрывающей — проверьте, что стек не пуст и на вершине соответствующая открывающая (удобна map `pairs := map[rune]rune{')': '(', ']': '[', '}': '{'}`).
@@ hint
В конце стек должен быть пуст.

@@ solution
package main

import "fmt"

func IsBalanced(s string) bool {
	pairs := map[rune]rune{')': '(', ']': '[', '}': '{'}
	var stack []rune
	for _, r := range s {
		switch r {
		case '(', '[', '{':
			stack = append(stack, r)
		case ')', ']', '}':
			if len(stack) == 0 || stack[len(stack)-1] != pairs[r] {
				return false
			}
			stack = stack[:len(stack)-1]
		}
	}
	return len(stack) == 0
}

func main() {
	fmt.Println(IsBalanced("{[()()]}"), IsBalanced("([)]"))
}
@@ test
package main

import "testing"

func TestIsBalanced(t *testing.T) {
	cases := map[string]bool{
		"{[()()]}":               true,
		"([)]":                   false,
		"(((":                    false,
		")(":                     false,
		"func() { return a[i] }": true,
		"":                       true,
		"no brackets":            true,
		"}":                      false,
		"[{}](){}[[]]":           true,
		"[{]}":                   false,
		"(]":                     false,
	}
	for in, want := range cases {
		if got := IsBalanced(in); got != want {
			t.Errorf("IsBalanced(%q) = %v, ожидалось %v", in, got, want)
		}
	}
}
