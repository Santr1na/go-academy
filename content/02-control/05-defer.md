## Что делает defer

`defer` откладывает вызов функции до момента **выхода из текущей функции** — по `return`, при достижении конца или при панике. Классическое применение — освобождение ресурсов рядом с их захватом:

```go
f, err := os.Open("data.txt")
if err != nil {
	return err
}
defer f.Close() // файл закроется при любом выходе из функции

mu.Lock()
defer mu.Unlock()
```

## Правило 1: порядок LIFO

Отложенные вызовы складываются в стек и выполняются **в обратном порядке**:

```go
for i := range 3 {
	defer fmt.Print(i, " ")
}
// выведет: 2 1 0
```

## Правило 2: аргументы вычисляются сразу

Аргументы отложенного вызова вычисляются **в момент выполнения инструкции `defer`**, а не при выходе:

```go
x := 1
defer fmt.Println("defer:", x) // запомнено x = 1
x = 2
fmt.Println("now:", x)
// now: 2
// defer: 1
```

Если нужно актуальное значение — используйте замыкание: `defer func() { fmt.Println(x) }()`.

То же касается получателя метода: `defer obj.Method()` вычисляет `obj` сразу.

## Правило 3: defer может изменить именованный результат

Отложенная функция выполняется **после** того, как `return` присвоил значения результатам, но **до** возврата управления вызывающему:

```go
func double() (result int) {
	defer func() { result *= 2 }()
	return 21 // result = 21, затем defer: result = 42
}
```

Это используется для обработки ошибок:

```go
func process() (err error) {
	defer func() {
		if err != nil {
			err = fmt.Errorf("process: %w", err)
		}
	}()
	// ...
	return errors.New("сбой")
}
```

## defer и циклы

> **Ловушка:** `defer` внутри цикла выполнится только при выходе из **функции**, а не итерации. Открыв 10 000 файлов в цикле с `defer f.Close()`, вы держите их все открытыми до конца функции. Выносите тело цикла в отдельную функцию.

## Стоимость

Начиная с Go 1.14 большинство `defer` реализовано через «open-coded defers» и стоит почти ничего. Не бойтесь использовать `defer` ради корректности.

## os.Exit и defer

`os.Exit` завершает программу **немедленно**, отложенные вызовы не выполняются. `log.Fatal` вызывает `os.Exit(1)`.

## Разбираем подробнее: что происходит в момент return

Строка `return x` выглядит как одно действие, но на самом деле их три:

1. значение `x` вычисляется и **записывается в результат** функции;
2. выполняются отложенные вызовы — в обратном порядке;
3. функция возвращает управление вместе с тем, что лежит в результате.

Отложенная функция работает на шаге 2 — после того как результат уже записан. Отсюда вся разница между именованным и безымянным результатом:

```go
func a() int { // результат безымянный
	n := 10
	defer func() { n++ }()
	return n // шаг 1: в результат скопировано 10
}            // шаг 2: n стало 11, но результат — отдельная копия. Вернётся 10

func b() (n int) { // результат называется n
	defer func() { n++ }()
	return 10 // шаг 1: n = 10
}             // шаг 2: n++ меняет сам результат. Вернётся 11
```

В `a` переменная `n` и результат — две разные «коробки». В `b` это одна и та же коробка, поэтому отложенная функция до неё дотягивается.

### Что вычисляется сразу, а что потом

| Часть строки `defer` | Когда вычисляется |
|---|---|
| аргументы вызова: `defer fmt.Print(x)` | сразу, в момент `defer` |
| получатель метода: `defer t.Print()` | сразу — значение `t` копируется |
| вложенные вызовы в аргументах: `defer fmt.Print(v("a"))` | `v("a")` выполнится сразу, `Print` — потом |
| тело анонимной функции: `defer func() { fmt.Print(x) }()` | потом, при выходе; `x` читается в тот момент |

Пример с вложенным вызовом:

```go
func v(s string) string { fmt.Print(s); return s }

func main() {
	defer fmt.Print(v("a")) // v("a") печатает a прямо сейчас
	defer fmt.Print(v("b")) // v("b") печатает b прямо сейчас
	fmt.Print("c")
}
// Вывод: abcba
```

Сначала `a` и `b` от немедленно выполненных `v`, затем `c`, а при выходе — отложенные `Print` в обратном порядке: `b`, потом `a`.

### Типичные применения

```go
f, err := os.Open(path)
if err != nil {
	return err
}
defer f.Close() // сначала проверка ошибки, потом defer

mu.Lock()
defer mu.Unlock() // мьютекс освободится на любом пути выхода

start := time.Now()
defer func() { log.Println("заняло", time.Since(start)) }()
```

### Частые ошибки

- **`defer` раньше проверки ошибки.** Если `os.Open` вернул ошибку, `f` равен `nil`, и `defer f.Close()` перед `if err != nil` приведёт к панике при выходе.
- **`defer` в длинном цикле.** Отложенные вызовы выполняются при выходе из **функции**, а не из итерации: тысяча открытых в цикле файлов закроется только в самом конце. Тело цикла выносят в отдельную функцию.
- **Ожидание «свежего» значения в аргументах.** `defer fmt.Println(x)` запомнит `x` сейчас. Нужно значение на момент выхода — оберните в анонимную функцию.

Реализуйте `Trace(log *[]string, name string) func()`:

- при вызове `Trace` добавляет в `*log` строку `"enter " + name`;
- возвращает функцию, которая при вызове добавляет `"exit " + name`.

Идиоматичное использование: `defer Trace(&log, "f")()` — обратите внимание на **две пары скобок**: `Trace` вызывается сразу (enter), а возвращённая функция откладывается (exit).

Также реализуйте `Run(log *[]string)`, которая использует `Trace` так, чтобы итоговый лог был:

```
enter outer
enter inner
exit inner
exit outer
```

Для этого внутри `Run` объявите вложенную логику: функция «outer» вызывает «inner» (можно через анонимные функции).

package main

import "fmt"

func Trace(log *[]string, name string) func() {
	*log = append(*log, "enter "+name)
	return func() {
		*log = append(*log, "exit "+name)
	}
}

func Run(log *[]string) {
	outer := func() {
		defer Trace(log, "outer")()
		inner := func() {
			defer Trace(log, "inner")()
		}
		inner()
	}
	outer()
}

func main() {
	var log []string
	Run(&log)
	fmt.Println(log)
}

package main

import (
	"strings"
	"testing"
)

func TestTrace(t *testing.T) {
	var log []string
	func() {
		defer Trace(&log, "a")()
		if len(log) != 1 || log[0] != "enter a" {
			t.Fatalf("enter должен записываться сразу, лог: %v", log)
		}
	}()
	if strings.Join(log, ",") != "enter a,exit a" {
		t.Errorf("лог %v, ожидалось [enter a exit a]", log)
	}
}

func TestRun(t *testing.T) {
	var log []string
	Run(&log)
	want := "enter outer,enter inner,exit inner,exit outer"
	if got := strings.Join(log, ","); got != want {
		t.Errorf("Run: лог %q, ожидалось %q", got, want)
	}
}
