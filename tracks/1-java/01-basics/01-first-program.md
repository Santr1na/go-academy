## Как запускается Java-программа

Java — компилируемый язык, но компилируется он не в машинный код, а в **байт-код**. Байт-код исполняет виртуальная машина — **JVM**. Поэтому одна и та же программа работает на Windows, Linux и macOS без пересборки.

```text
Main.java  --javac-->  Main.class (байт-код)  --java-->  JVM исполняет
```

Три сокращения, которые обязательно спросят на собеседовании:

| Что | Расшифровка | Что внутри |
|---|---|---|
| **JVM** | Java Virtual Machine | исполняет байт-код, управляет памятью (сборщик мусора) |
| **JRE** | Java Runtime Environment | JVM + стандартная библиотека — достаточно, чтобы *запускать* программы |
| **JDK** | Java Development Kit | JRE + компилятор `javac` и инструменты — нужно, чтобы *писать* программы |

## Минимальная программа

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, Java!");
    }
}
```

Разберём по словам:

- `public class Main` — в Java весь код живёт внутри **классов**. Публичный класс должен называться так же, как файл: класс `Main` — файл `Main.java`.
- `public static void main(String[] args)` — **точка входа**. JVM ищет метод именно с такой сигнатурой и начинает выполнение с него.
  - `public` — метод доступен снаружи (его вызывает JVM);
  - `static` — метод принадлежит классу, для вызова не нужен объект;
  - `void` — метод ничего не возвращает;
  - `String[] args` — аргументы командной строки.
- `System.out.println(...)` — печатает строку и переводит курсор на новую строку. `System.out.print(...)` — печатает без перевода строки.
- Каждая команда заканчивается **точкой с запятой**. Блоки кода заключаются в фигурные скобки.

## Вывод и склейка строк

```java
System.out.println("Мне " + 25 + " лет");   // Мне 25 лет
System.out.println(1 + 2 + "3");            // 33
System.out.println("1" + 2 + 3);            // 123
```

Оператор `+` работает слева направо. Пока слева и справа числа — это сложение. Как только один из операндов строка — это склейка, и дальше всё превращается в строку. Поэтому `1 + 2 + "3"` — это `3 + "3"` = `"33"`, а `"1" + 2 + 3` — это `"12" + 3` = `"123"`.

> **Ловушка.** `System.out.println('a' + 'b')` напечатает `195`, а не `ab`. Одинарные кавычки — это тип `char` (символ), а символы при сложении превращаются в числа — свои коды. Строки пишут в двойных кавычках.

@@ q
Что выведет код?
```java
System.out.println(1 + 2 + "3" + 4 + 5);
```
- [ ] `15`
- [ ] `12345`
- [x] `3345`
- [ ] `339`
@@ explain
Слева направо: `1 + 2` — числа, получается `3`. Затем `3 + "3"` — уже склейка: `"33"`. Дальше всё приклеивается как текст: `"334"`, `"3345"`.

@@ q
Что выведет код?
```java
System.out.println('a' + 'b');
```
- [ ] `ab`
- [x] `195`
- [ ] `a+b`
- [ ] Ошибка компиляции
@@ explain
`'a'` и `'b'` — значения типа `char`. При сложении они превращаются в числа (коды символов 97 и 98), результат — `int` 195. Для склейки нужны строки в двойных кавычках: `"a" + "b"`.

@@ q
Почему метод `main` объявлен как `static`?
- [ ] Чтобы он работал быстрее
- [x] Чтобы JVM могла вызвать его, не создавая объект класса
- [ ] Потому что он ничего не возвращает
- [ ] Так положено для всех методов в Java
@@ explain
Статический метод принадлежит классу, а не объекту. В момент старта программы никаких объектов ещё нет, поэтому точка входа обязана быть статической.

@@ task hello | Первая программа | xp=20
Допишите программу так, чтобы она напечатала ровно две строки:

```text
Привет, Java!
2 + 3 = 5
```

Число `5` во второй строке должно быть посчитано программой: используйте выражение `2 + 3`, а не готовый текст.
@@ hint
`System.out.println("текст")` печатает строку и переходит на новую.
@@ hint
Чтобы сначала сложить числа, а потом приклеить результат к тексту, возьмите сложение в скобки: `"2 + 3 = " + (2 + 3)`. Без скобок получится `2 + 3 = 23`.
@@ starter
public class Main {
    public static void main(String[] args) {
        // напечатайте две строки
    }
}
@@ solution
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, Java!");
        System.out.println("2 + 3 = " + (2 + 3));
    }
}
@@ test
public class Checker {
    public static void main(String[] args) {
        T.test("первая строка", () -> {
            String[] lines = T.out(() -> Main.main(new String[0])).split("\n");
            T.eq("Привет, Java!", lines[0].strip());
        });
        T.test("вторая строка", () -> {
            String[] lines = T.out(() -> Main.main(new String[0])).split("\n");
            T.check(lines.length == 2, "ожидалось 2 строки, напечатано " + lines.length);
            T.eq("2 + 3 = 5", lines[1].strip());
        });
        T.done();
    }
}
